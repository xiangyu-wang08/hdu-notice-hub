## Release 正文草稿

以下内容可用作正式 Release 正文：

> 杭电通知集 V1.0.0 是首个开源版本，将 25 个选定公开通知栏目汇集到本机网页，支持来源、时间范围和标题关键词筛选、官方原文跳转与本地缓存。
>
> Windows 10 / 11 x64 用户下载 `hdu-notice-hub-V1.0.0-windows-x64.zip`，完整解压后运行 `杭电通知集.exe`。保留 `_internal` 文件夹；使用结束后运行 `关闭服务.cmd`。源码用户下载 `hdu-notice-hub-V1.0.0-source.zip`，使用 Python 3.10+ 执行 `python portable_launcher.py`，正常运行无需安装第三方包。
>
> 每个来源每次最多读取五页。时间筛选只作用于已获取内容，本项目不提供实时或全量通知保证；通知要求与附件以官方原文为准。项目由学生开发，非学校官方平台。
>
> 初次使用请阅读附带的 `hdu-notice-hub-V1.0.0-install.pdf` 或仓库中的 `docs/INSTALL.md`。代码与文档按 MIT 许可开源，第三方组件保留各自许可。

发布后应核对下载链接和三个附件均可访问，再更新本文件的本地准备状态；不能只凭上传命令返回成功就宣称发布可用。
