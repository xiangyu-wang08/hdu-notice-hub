GitHub Actions 已配置 Windows 的 Python 3.10 / 3.12 单元与离线集成测试；远端运行结果需在授权推送后检查。本机实测系统为 Windows 11，不代表所有 Windows 10/11 设备均已实测。

Setup.exe 使用实际安装目录完成安装、启动、运行中覆盖安装和卸载检查；桌面／开始菜单快捷方式和当前用户卸载登记正确创建／移除，缓存与额外文件保持不变。安装向导采用 NSIS 标准中文界面，实机测试使用静默模式。

## 修复记录

- 统一源码入口与免安装入口，修复原固定端口脚本无法回退的问题。

- 修复学校官网部分列表标题截断；仅接受与可见标题前缀匹配且自身完整的标题属性，其他模板和不可靠属性保持原行为。三个回归测试已验证。
- 发布包输出改为当前源码目录下的 `release/V1.0.0/`，包含文档和许可证；拒绝混入运行状态的构建目录。

## 可重复命令

```powershell
python -B -m unittest discover -s tests -v
python -B packaging/smoke_test.py --source
python -B packaging/smoke_test.py --source --scripts
python -B packaging/smoke_test.py --bundle release/V1.0.0/免安装程序 --concurrent
python -B packaging/test_portable.py --online
```

联网命令依赖官网当时的可访问性，不用于离线 CI。Windows 程序由固定依赖的 Python 3.12 构建；PDF 构建依赖与应用运行依赖分离。
