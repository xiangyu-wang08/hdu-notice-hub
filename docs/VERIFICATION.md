## HTML 解析安全修复

发现约 480 KB 的合成恶意 HTML 可使正文解析阻塞约 18 秒。修复增加 HTML 节点数量与嵌套深度限制，并使解析及正文渲染遵守与下载相同的总时限；该样例在本机修复后约 0.025 秒即被拒绝。此耗时反映该样例及本机环境，不构成所有页面的性能保证。

新增的 4 项回归分别覆盖过深嵌套、过多节点、HTML 解析阶段总时限和正文渲染阶段总时限，单元测试总数由 87 项增加到 91 项。超过复杂度或时限的网页返回安全的失败提示，不作为可用正文提交给模型。

## 可重复命令

以下命令在源码根目录执行，单元测试应分别使用待验证的 Python 解释器：

```powershell
python -B -m unittest discover -s tests -v
node tests/frontend_regression.cjs
python -B packaging/smoke_test.py --source
python -B packaging/smoke_test.py --source --scripts
python -B packaging/smoke_test.py --bundle release/V1.0.1/免安装程序 --concurrent
python -B packaging/test_portable.py
python -B packaging/test_installer_windows.py
python -B packaging/test_installer_windows.py --upgrade-from release/V1.0.0/hdu-notice-hub-V1.0.0-windows-x64-Setup.exe
```

安装验收脚本会拒绝覆盖已有注册项或快捷方式，应使用隔离测试环境。额外联网验收可使用 `python -B packaging/test_portable.py --online`，它依赖当时官网可访问性，不用于日常离线 CI。应用运行只使用 Python 标准库；构建和 PDF 生成使用独立依赖。
