# 杭电通知集 V1.0.1 安装与使用手册

适用项目：[xiangyu-wang08/hdu-notice-hub](https://github.com/xiangyu-wang08/hdu-notice-hub)。

杭电通知集将 25 个选定公开通知栏目的标题、发布日期和原文链接汇集到本机网页，并提供可选的“问问 AI”辅助阅读。它是学生开发项目，非学校官方平台；通知正文、附件、截止时间和办理要求请以官方原文为准。

## 1. 先选择使用方式

| 方式 | 适用情况 | 需要准备 |
| --- | --- | --- |
| Windows 安装版（推荐） | 下载一个 Setup.exe 并安装，之后使用快捷方式 | Windows 10 / 11 x64、浏览器 |
| Windows 免安装版 | 希望下载后直接使用 | Windows 10 / 11 x64、浏览器、可写文件夹 |
| Python 源码版 | 已有 Python，或希望阅读、修改代码 | Python 3.10+、浏览器、完整源码 |

免安装版不需要安装 Python、Node.js、Codex 或第三方依赖。默认普通搜索不需要学校账号或 API Key；可选 AI 功能需要自行配置兼容 OpenAI 的 HTTPS 接口、API Key 和模型名，可能产生服务商费用。源码版正常运行仅使用 Python 标准库，无需 `pip install`。获取新通知、打开原文及使用 AI 需要网络；查看已保存的列表可以离线进行。

本手册主要说明 Windows 操作。安装版和便携版发布包均面向 Windows x64。源码的普通搜索可在具备相应 Python 环境的系统中运行；AI 设置中的 Key 加密保存依赖当前 Windows 用户的 DPAPI。

```powershell
$file = Join-Path $env:USERPROFILE 'Downloads'

```

若浏览器把文件保存到别处，请把命令中的路径换成实际文件路径。

## 3. 使用 Windows 安装版（推荐）

### 3.1 下载与安装

在 V1.0.1 发布页点击 `hdu-notice-hub-V1.0.1-windows-x64-Setup.exe`。下载完成后双击，按中文安装向导接受 MIT 许可、确认目录并安装。不需要先解压 ZIP，也不需要安装 Python。

默认目录为 `%LOCALAPPDATA%\Programs\HDUNoticeHub`，安装和快捷方式只面向当前用户，不要求管理员权限。也可以选择空目录，或本程序已有的安装目录；安装程序会拒绝覆盖不属于本程序的非空目录。

### 3.2 启动与关闭

安装完成后使用桌面或开始菜单中的“杭电通知集”快捷方式。也可以在安装完成页面勾选运行。浏览器会自动打开通知网页，点击“一键获取通知”即可使用。

启动时的服务窗口需要保持运行，可以最小化。结束时从开始菜单选择“杭电通知集 → 关闭服务”，或者在服务窗口按 Ctrl+C、关闭该窗口。只关闭浏览器不会停止服务。开始菜单同时提供安装手册入口。

### 3.3 升级与卸载

升级时下载新版 Setup.exe，安装到原目录；安装程序先关闭本程序服务，再替换程序文件并保留 `data/` 中的通知缓存和 AI 设置。由 V1.0.0 升级时沿用已有缓存，AI 三项配置首次为空。安装程序不会设置开机自启。

卸载时使用 Windows“设置 → 应用”中的“杭电通知集”，或开始菜单的“卸载”。卸载会关闭服务、移除程序文件、快捷方式和当前用户卸载登记，保留 `data/` 和额外添加的文件。若不再需要保存 Key，可先在“AI 设置”中清除；如需彻底删除，先备份所需内容，再手工删除残留安装目录。

安装版网页功能、端口和筛选规则与下文便携版相同。

## 4. 使用 Windows 免安装版

### 4.1 确认电脑类型

在 Windows“设置 → 系统 → 系统信息／关于”中查看“系统类型”，确认是 x64 系统。本发布包不面向 32 位 Windows 或原生 ARM64 环境。

### 4.2 完整解压

1. 在文件资源管理器中找到下载的 ZIP。
2. 右键选择“全部解压缩”，将其解压到桌面、文档或其他你有写入权限的普通文件夹。
3. 打开解压后的程序目录，找到 `杭电通知集.exe`。
4. 确认同级保留 `_internal` 文件夹和 `关闭服务.cmd`。

不要在压缩软件的预览窗口中直接运行。不要只复制 EXE；`_internal` 包含运行环境和网页资源，缺少它会导致启动失败。使用期间不要移动或删除程序目录。

### 4.3 启动

双击 `杭电通知集.exe`。出现服务窗口后，浏览器会自动打开网页。服务窗口可以最小化，使用期间应保持运行。

默认网页地址为 `http://127.0.0.1:8765/`。如果该端口已被使用，启动器会依次尝试 `8766` 至 `8775`，请以窗口显示的地址为准。浏览器没有自动打开时，复制服务窗口里的完整地址，粘贴到浏览器地址栏。

`127.0.0.1` 表示当前电脑。此服务只监听本机地址，不是可转发给朋友使用的公网网址；手机访问自己的 `127.0.0.1` 也不会连接到电脑上的程序。

### 4.4 第一次获取通知

1. 保持电脑联网，点击网页中的“一键获取通知”。
2. 等待各来源完成读取。不同来源独立显示状态，不必等所有来源都成功才能查看已有内容。
3. 展开“通知来源”，点击来源的“查看详情”，核对错误、读取页数和数据日期范围。
4. 点击通知条目中的原文链接，在官方网页核实完整要求与附件。

全新安装没有历史缓存，列表为空是正常现象；AI 设置中的 Base URL、API Key 和模型名也均为空。正式发布包不包含使用者的 `data/`、历史通知、AI 配置、日志或凭据。

### 4.5 关闭和再次启动

双击同目录的 `关闭服务.cmd`。也可以在启动时的服务窗口按 `Ctrl+C`，或关闭该服务窗口。看到服务停止提示后，再关闭网页即可。

只关闭浏览器标签页不会停止本地服务。程序不会自动设置开机启动；下次使用重新双击 EXE。再次启动时会恢复本地缓存，并在你点击获取后联网更新。

## 5. 使用 Python 源码版

### 5.1 安装或检查 Python

如果已安装 Python，在 PowerShell 或命令提示符中运行：

```powershell
python --version
```

确认输出为 Python 3.10 或更高版本。若电脑同时安装多个版本，也可用 `py -3.12 --version` 检查已安装的 Python 3.12。

如果没有 Python，从 [Python 官方 Windows 下载页](https://www.python.org/downloads/windows/) 获取适合电脑的正式安装程序。使用传统安装器时可选择为当前用户安装，并按安装界面的选项启用 Python 命令；不同安装方式可参考 [Python 官方 Windows 使用说明](https://docs.python.org/3.12/using/windows.html)。安装后关闭旧终端，重新打开终端并再次检查版本。

本项目的 Windows 打包环境使用 Python 3.12；源码运行最低要求为 Python 3.10。不要把没有安装解释器、只打开商店或安装提示的 `python` 命令当作可用环境。

### 5.2 下载并打开源码目录

完整解压 `hdu-notice-hub-V1.0.1-source.zip`。打开包含下列内容的目录：

```text
portable_launcher.py
server.py
sources.py
ai_service.py
notice_content.py
web/
```

在文件资源管理器地址栏输入 `powershell` 并回车，即可在当前目录打开终端。也可以先打开终端，再切换目录，例如：

```powershell
Set-Location -LiteralPath 'D:\Apps\hdu-notice-hub'
```

上面是示例路径，请替换为你实际解压得到的目录，不必创建同名文件夹。

### 5.3 启动与停止

在源码根目录运行：

```powershell
python portable_launcher.py
```

保留终端窗口，使用浏览器自动打开的网页。端口选择和通知获取步骤与免安装版相同。

停止时可在该窗口按 `Ctrl+C`；也可在同一源码目录新开终端，执行：

```powershell
python portable_launcher.py --stop
```

如果 `python` 不可用，但 `py -3.12` 检查正常，可以将上述命令的 `python` 换为 `py -3.12`。不要混用不同项目目录里的启动和停止命令。

### 5.4 可选：使用虚拟环境

运行本项目不要求虚拟环境。如果希望与其他 Python 项目分开，在源码根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe portable_launcher.py
```

停止命令为：

```powershell
.\.venv\Scripts\python.exe portable_launcher.py --stop
```

这组命令直接使用虚拟环境解释器，无需运行激活脚本，也无需更改 PowerShell 执行策略。普通使用不要安装 `packaging/build-requirements.txt`；那是制作 EXE 时才需要的构建依赖。

### 5.5 开发时手动指定端口

需要固定其他端口时，可直接启动服务：

```powershell
python server.py --port 8766
```

然后在浏览器打开 `http://127.0.0.1:8766/`。这种方式不自动打开浏览器，也不提供启动器的自动端口回退；请在运行此命令的终端按 `Ctrl+C` 停止。`portable_launcher.py --stop` 只负责通过启动器运行的实例。

## 6. 理解筛选与读取状态

### 6.1 覆盖范围

本版本接入 6 个校级平台和 19 个学院／教学单位，共 25 个选定公开栏目。校级平台包括教务处、学校官网、图书馆、研究生院、就业网和学工部。完整清单见 [README](../README.md)。

每次每个来源最多读取五页，不保证覆盖全校、所有栏目或全部历史通知。时间筛选只作用于已读取内容，因此“近 90 天”不代表这 90 天的通知已被全部读取，“全部已获取”也不等于全部历史通知。

### 6.2 筛选与原文

- “全部来源／校级平台／学院／教学单位”用于筛选分组，“具体来源”用于进一步选择栏目。
- 时间范围可选近 7 天、近 30 天、近 90 天或全部已获取，依据通知发布日期筛选。
- 普通搜索框匹配通知标题，不搜索正文或附件；AI 按第 7 节读取所选通知的公开 HTML 正文。
- 默认分批显示列表，点击“再显示 20 条”继续浏览。
- 图书馆等来源的部分原文可能指向微信公众号；可点击官方原文打开，AI 不保证能够读取这些正文，失败会说明原因。

### 6.3 状态判断

| 状态 | 如何理解 |
| --- | --- |
| 待获取 | 还没有进行首次获取。 |
| 获取中 | 正在读取官网，已有内容仍可查看。 |
| 已更新 | 本次最多五页的读取完成。 |
| 部分获取 | 本次读到部分数据后发生错误，已获取内容与此前可用数据保留。 |
| 获取失败 | 本次未获得可用数据，先前缓存可能仍然可见。 |
| 待验证 | 历史缓存无法确认上一次读取结果，应联网重新获取。 |
| 缓存标记 | 内容从本机读取，不能据此判断内容最新或读取成功。 |

“完整读取”时间只表示在本次最多五页范围内没有读取错误。获取失败时不要根据列表仍有内容就判断官网已更新成功；请同时查看该来源的状态和时间。

点击“重试失败来源”只重试部分获取和失败的来源。两次获取之间至少等待 30 秒；间隔不足时，等待后再试，避免反复点击。

## 7. 可选：使用问问 AI

### 7.1 配置自己的接口

打开网页中的“AI 设置”，填写下列三项。项目不预填平台、模型或共享 Key，使用者自行选择服务并承担其费用。

| 项目 | 填写说明 |
| --- | --- |
| Base URL | 兼容 OpenAI 的 HTTPS 接口地址，可填到 `/v1` 等兼容前缀；程序追加 `/chat/completions`，也接受完整聊天端点。 |
| API Key | 服务商提供的个人 Key，仅用于你配置的服务。 |
| 模型名 | 手动填写服务商支持的准确模型名称。 |

点击“保存设置”只保存，不调用模型。点击“测试连接”则使用当前表单发送一次短提示词请求，测试不会保存输入，也不需要先保存。测试与正常提问的输出预算均为最多 **1500 tokens（包含模型思考）**，可能产生费用，程序均不自动重试。测试成功后仍需点击保存才能保留新填内容。

Key 通过当前 Windows 用户的 **DPAPI** 加密写入程序目录的 `data/ai-settings.json`；Base URL 与模型名作为普通配置保存在该文件。Key 不以明文落盘、回显或写入日志，也不保存到浏览器存储。页面仅显示是否已保存。已有可用 Key 时，密码框留空再保存会保留它；输入新 Key 后保存可替换，点击“清除已保存的 Key”可删除本机保存的 Key。

加密 Key 依赖当前电脑和 Windows 用户，便携目录复制到另一台电脑、换 Windows 用户或重装系统后可能无法解密，应重新填写。普通搜索不依赖 AI 配置。

### 7.2 选择通知并提问

1. 先获取通知，按来源、时间和标题关键词找到需要阅读的内容。
2. 切换“问问 AI”。程序默认选中当前筛选结果中最新的 5 条，最多选择 10 条；可以手动增减。
3. 填写最多 1000 字的问题。留空时默认整理主要内容、重要日期和个人需要完成的事项。
4. 确认愿意将问题和所选正文发送给已配置的平台，再点击“问问 AI”。这一步可能产生费用。
5. 查看读取进度、回答、“本次选中的通知”以及“正文来源与读取情况”，点击原文核对要求。

改变来源、时间或关键词后，会重新默认选择最新 5 条；点击“再显示 20 条”保留勾选。任务以点击提问时的通知快照为准，后续筛选或获取不改变本次范围。一次仅运行一个 AI 操作，连接测试也计入其中。回答仅保存在当前服务内存，重启后不保留。

### 7.3 读取范围与失败说明

普通获取只读取列表；AI 提问才按需读取选中通知的公开 HTML 正文，**不解析附件、不做 OCR**。报名表、附件中的截止时间、图片内文字等应直接查看官方原文及附件。

正文最多 4 路并发读取，单页超时 15 秒；每篇最多 6000 字，整批最多 30000 字，超出时保留首尾并显示截断提示。没有可用正文时不调用模型；部分失败时列出未读取的通知及原因，不能从标题推断为已读正文。模型请求最多等待 90 秒，不自动重试。

回答以纯文本显示，程序另外列出正文来源、原文链接和读取情况。接口认证失败、额度不足、超时、输出预算耗尽导致空回答、仅返回思考内容等会给出对应提示。回答仍可能遗漏或误读，请核对官方日期、办理要求和附件。

## 8. 数据保存、离线、升级与卸载

### 8.1 本机保存位置

程序在自身目录下创建 `data/`：`notices.json` 保存已获取的列表，`ai-settings.json` 保存 AI 接口配置与 DPAPI 加密 Key。启动器还会使用 `portable-runtime.json` 记录本机运行实例信息；它是运行控制文件，不是通知备份。

源码版的数据目录与源码同级；免安装版的数据目录与 EXE 同级。程序不要求写入管理员目录。发布包排除整个 `data/`、运行记录与凭据；转交程序请使用干净的正式发布 ZIP，勿发送自己运行后的目录或 AI 配置。

### 8.2 离线使用

曾经成功保存缓存后，离线启动仍可查看并筛选本地列表。离线不能获取新通知或使用 AI，原文和附件也可能无法打开。缓存反映上次获取结果，请留意来源状态、发布日期和更新时间。

### 8.3 升级

安装版按照第 3.3 节运行新版 Setup.exe。下面步骤适用于便携 ZIP 和源码 ZIP：

1. 关闭旧版服务。
2. 如需保留数据，先将旧目录中的 `data/` 复制到自己的独立备份位置；其中可能包含加密 Key，请勿公开分享。
3. 将新版 ZIP 完整解压到一个新文件夹，不要在运行中的目录里覆盖文件。
4. 先确认新版能够启动。服务停止时，可将备份的 `notices.json` 放入新版 `data/`。已有 AI 配置可在同一电脑、同一 Windows 用户下迁移 `ai-settings.json`；换电脑或 Windows 用户请重新填写 Key。
5. 重新启动并联网获取；如果提示缓存无法读取，保留备份，重新获取即可。

从 V1.0.0 升级到 V1.0.1 可沿用已有通知缓存；旧版没有 AI 配置，首次自行填写即可。全新解压不迁入数据时，通知列表和 AI 三项均为空。不要迁移 `portable-runtime.json`，也不要把旧版 `_internal` 与新版混合；后续版本的兼容性以对应说明为准。

### 8.4 卸载

安装版使用第 3.3 节的 Windows 应用卸载或开始菜单入口，默认保留缓存；下面的直接删除方式适用于便携版与源码版。

关闭服务后，删除整个解压文件夹即可。需要保留记录时先备份 `data/`，不再需要 Key 时可先在 AI 设置中清除。程序不自动设置开机启动。

## 9. 常见问题

### 双击后没有页面，或提示缺少文件

安装版先关闭服务，再重新运行 Setup.exe 安装到原目录。以下文件检查适用于便携 ZIP 版本：

确认 ZIP 已完整解压，EXE 与 `_internal` 仍在同一个目录，并且目录可写。重新从项目发布页下载、核对校验值并解压到新目录。若有错误窗口，记录完整内容；不要只转发 EXE。

### Windows 或安全软件拦截程序

先核实下载来源、文件校验值和具体检测信息。若仍有疑问，保留提示内容并向项目反馈，或使用可阅读的源码运行方式。不要为运行本项目关闭杀毒软件、关闭系统防护或批量添加排除项。

### 显示“8765 至 8775 端口均不可用”

检查是否已启动多个程序实例，先使用各自目录里的关闭命令停止它们。不要随意终止不认识的进程。源码版可用 `python server.py --port 8766` 之类的命令指定一个确认空闲的端口，并按前文的手动服务方式操作。

### 网页能打开，但没有通知

首次使用先点击“一键获取通知”。确认没有设置过窄的来源、时间或关键词筛选，尝试选择“全部来源”和“全部已获取”，清空搜索框。然后展开来源详情，区分栏目为空、未获取、部分获取和失败。

### 显示无法连接、DNS 或超时错误

在同一网络的浏览器中打开该来源的官方栏目，确认电脑联网。官网不可访问时等待恢复后重试；官网可访问而程序持续失败时，反馈来源、发生时间及完整错误。DNS 故障发生在域名连接阶段，不代表官网没有新通知。不要把临时恢复当作永久修复，也不要从不明来源复制固定 IP 或修改系统网络配置。

### 只有部分来源失败

各官网独立运行，可能受网络、维护、访问限制或页面结构变化影响。其他来源的结果仍可使用；查看失败详情，等待 30 秒后点击“重试失败来源”。若提示未找到列表或结构变化，请附官方栏目地址向项目反馈。

### 显示“无法保存本地缓存”

本次结果可能仍在网页中，但关闭后不一定保留。先关闭服务，再把完整程序目录放到有写入权限的位置，例如自己的文档目录，重新启动并获取。避免从只读介质或受保护的系统目录直接运行。

### 输入 `python` 打开商店，或提示找不到命令

这通常表示当前命令没有找到可用解释器。按第 5.1 节安装并验证 Python；若 `py -3.12 --version` 正常，直接使用 `py -3.12 portable_launcher.py`。使用解释器完整路径时，PowerShell 的写法为 `& '你的Python路径\python.exe' portable_launcher.py`。

### 停止服务后网页仍然显示内容

已经显示的页面可能仍留在标签页中。点击获取会无法连接；这不表示服务仍在运行。可关闭网页；下次启动后使用新的服务窗口地址访问。

### AI 配置无法使用，或换电脑后提示无法解密

确认 Base URL 使用 HTTPS、模型名准确、Key 有效，按服务商说明检查额度和访问权限。更换电脑或 Windows 用户后重新输入 Key 并保存；同一用户升级安装会保留原数据。连接测试会收费且不自动保存，手工重试前先确认上一次结果。

### AI 显示读取失败、没有正文或空回答

打开所列原文核对页面是否可访问。附件、扫描图片、访问限制或不支持的页面可能没有可用 HTML 正文；可减少选择数量后再次提交。若提示输出预算耗尽或仅返回思考内容，按服务商支持情况选择适合的模型。程序不会自动再次发出付费请求，请结合提示自行决定是否重试。
