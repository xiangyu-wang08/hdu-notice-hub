## 本版变化

默认保留普通搜索，新增可选“问问 AI”：默认选择当前筛选结果中最新的 5 条，最多选择 10 条，按需读取公开 HTML 正文并基于所选内容回答。AI 不解析附件、不做 OCR，回答附本次范围、正文来源、原文链接和读取失败原因。没有可用正文时不调用模型。

AI 设置首次三项均为空，由使用者自行填写兼容 OpenAI 的 HTTPS Base URL、API Key 和模型名。Key 通过 Windows 当前用户的 DPAPI 加密保存，不使用明文、浏览器存储或日志保存 Key，支持替换和清除。提问和正文会发送到配置的平台，可能产生费用。

保存不调用模型；测试连接只发送一次短提示词请求，不保存输入。测试与正常提问均使用最多 1500 tokens 的输出预算（包含模型思考），不自动重试付费请求。AI 任务以提交时的选择为准，一次只执行一个 AI 操作，结果仅存于当前服务内存。

安装升级保留 `data/`。从 V1.0.0 升级可继续使用通知缓存，AI 首次自行配置；换电脑或 Windows 用户时重新填写 Key。全新安装不附带通知缓存、接口配置或凭据。

正文解析增加节点数量、嵌套深度与总时限保护，修复复杂 HTML 长时间阻塞的问题。新增 4 项复杂度及解析／渲染时限回归，单元测试总数由 87 项增加到 91 项。

## Release 正文草稿

杭电通知集 V1.0.1 新增可选“问问 AI”，同时保留默认普通搜索、25 个选定公开栏目、来源／时间／标题关键词筛选、官方原文链接和本地缓存。

“问问 AI”默认选择当前结果中最新 5 条，最多 10 条，仅按需读取公开 HTML 正文，不解析附件、不做 OCR。使用者自行配置兼容 OpenAI 的 HTTPS 接口、API Key 和模型名；问题及正文会发送至该服务，可能产生费用。Key 使用当前 Windows 用户的 DPAPI 加密保存，支持替换与清除；换电脑或 Windows 用户后需重新填写。

测试连接会发送一次短提示词请求，测试与正常提问均有最多 1500 tokens 的输出预算（包含模型思考），不自动重试。回答列出来源、处理范围与读取失败原因，具体要求、日期和附件请以官方原文为准。

本版同时限制 HTML 节点数量与嵌套深度，并对解析及正文渲染执行总时限，防止复杂页面长时间阻塞。

Windows 10 / 11 x64 用户推荐下载 `hdu-notice-hub-V1.0.1-windows-x64-Setup.exe`。免安装用户下载 `hdu-notice-hub-V1.0.1-windows-x64.zip`，完整解压并保留 `_internal` 后启动 EXE，结束时运行 `关闭服务.cmd`。源码用户下载 `hdu-notice-hub-V1.0.1-source.zip`，使用 Python 3.10+ 执行 `python portable_launcher.py`，运行无需安装第三方包。

安装升级保留原数据；全新安装的 AI 三项为空，发布包不包含任何个人 `data/`、接口配置或凭据。详细说明见 `hdu-notice-hub-V1.0.1-install.pdf` 或仓库的 `docs/INSTALL.md`。每个来源每次最多读取五页，不保证全校或历史通知的完整覆盖。学生开发项目，非学校官方平台，代码与文档采用 MIT 许可。
